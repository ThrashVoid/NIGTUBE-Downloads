# NIGTUBE for Windows

A native Rust music player for Windows, with YouTube Music browsing, a playback queue, synced lyrics and native audio controls.

[**Download the latest Windows build**](https://github.com/ThrashVoid/NIGTUBE-Downloads/releases/latest)

## Install

1. Open the latest release and download **NIGTUBE-Windows.zip** from Assets.
2. Extract the ZIP to a folder.
3. Run `NIGTUBE.exe`, keeping the `tools` folder beside it.

## Requirements and build status

- 64-bit Windows and Microsoft Edge WebView2 Runtime.
- Internet access for online features.
- FFmpeg and Node.js installed separately for MP3 preparation.
- This is a development build. Account features depend on upstream services and Google app publishing/verification status; availability is not guaranteed for every user.

The release includes the native application, an external [yt-dlp helper](https://github.com/yt-dlp/yt-dlp), and setup notes. No account sessions, browser profiles or private configuration are included. Source code is maintained privately.
